# 📊 SalesFlow

A modern sales pipeline management tool designed to streamline your sales operations and boost team productivity.

## ✨ Features

- **Pipeline Management** - Organize deals through customizable sales stages
- **Real-time Analytics** - Track metrics and performance at a glance
- **Team Collaboration** - Share updates and stay synchronized across your team
- **Customer Insights** - Comprehensive customer profiles and interaction history
- **Activity Tracking** - Log calls, emails, and meetings automatically

## 🚀 Quick Start

### Prerequisites
- Node.js 16+
- Git

### Installation

```bash
# Clone the repository
git clone https://github.com/FibreFlows/SalesFlow.git
cd SalesFlow

# Install dependencies
npm install

# Start the development server
npm start
```
